# Match3 Unity Intern Test 2025

This project was updated from the original match-3 swap gameplay into a tap-to-collect triple matching game.

## Gameplay Changes

- Replaced the original drag/swap match-3 gameplay.
- Players now tap fish items on the board to move them into the bottom cells.
- The bottom area contains 5 cells.
- In normal gameplay, an item moved into a bottom cell cannot be moved back to the board.
- When exactly 3 identical fish items are in the bottom cells, they are cleared automatically.
- The player wins by clearing the entire board.
- The player loses in normal mode when all 5 bottom cells are filled.
- The initial board is generated so the number of each fish type is divisible by 3.
- The initial board always contains all fish types.

## Game Modes

### Play

Standard gameplay mode.

- Tap board items to move them into the bottom cells.
- Clear sets of 3 identical fish.
- Win by clearing the board.
- Lose when the bottom cells are full.

### Autoplay

Automatic winning mode.

- The game automatically selects moves with the goal of winning.
- Each action has a 0.5 second delay.

### Auto Lose

Automatic losing mode.

- The game automatically selects moves with the goal of filling the bottom cells and losing.
- Each action has a 0.5 second delay.

### Time Attack

A separate timed game mode.

- The player has 60 seconds to clear the board.
- The player no longer loses when the bottom cells are filled.
- The player can tap an item in a bottom cell to return it to its original board position.
- The player loses if the board is not cleared within 1 minute.

## UI Changes

- Added a Home screen with the following UI buttons:
  - `PLAY`
  - `AUTOPLAY`
  - `AUTO LOSE`
  - `TIME ATTACK`
- These buttons are real scene UI objects, not generated by runtime code.
- Added separate result panels:
  - Win panel
  - Lose panel
- The game condition text is hidden in `Play`, `Autoplay`, and `Auto Lose`.
- The game condition text is only shown in `Time Attack` to display the timer.

## Animation Changes

- Added an animation when an item moves from the board to a bottom cell.
- Added an animation when an item returns from a bottom cell to the board in Time Attack mode.
- Added a clear animation for matched identical items by scaling them down to `0`.

## Main Modified Files

- `Assets/Scripts/Controllers/BoardController.cs`
  - Handles the new tap-to-collect gameplay.
  - Manages bottom cells.
  - Handles autoplay and auto lose logic.
  - Handles Time Attack item return logic.

- `Assets/Scripts/Board/Board.cs`
  - Generates the initial board using fish groups divisible by 3.
  - Ensures all fish types appear on the initial board.

- `Assets/Scripts/Board/Item.cs`
  - Stores each item's initial board cell.
  - Handles movement animation.
  - Handles scale-to-zero clear animation.

- `Assets/Scripts/Controllers/GameManager.cs`
  - Adds the new game modes.
  - Tracks win/lose state.
  - Shows or hides the timer text depending on the mode.

- `Assets/Scripts/UI/UIMainManager.cs`
  - Shows the correct win or lose panel.

- `Assets/Scripts/UI/UIPanelMain.cs`
  - Connects Home screen buttons to gameplay logic.
  - Uses serialized UI button references from the scene.

- `Assets/Scripts/UI/UIPanelWin.cs`
  - Handles the win panel.

- `Assets/Scripts/UI/UIPanelGameOver.cs`
  - Handles the lose panel.

- `Assets/Scenes/Game.unity`
  - Contains the added Home screen buttons.
  - Contains separate win and lose panels.

- `Assets/Resources/gamesettings.asset`
  - Sets Time Attack duration to 60 seconds.
